# AI Prompts Used — The Last Commit

This file documents the prompts used with AI assistance during the development of **The Last Commit**.

## 1. Project Planning

> I am building a full-stack hackathon website called "The Last Commit". Create a project plan using React, TypeScript, Node.js, Express, MongoDB and a proper admin portal. The website should be visually impressive, responsive, interactive and suitable for a hackathon event.

## 2. Frontend Design

> Design a modern, futuristic developer-themed website for a hackathon called "The Last Commit". Use a dark interface, neon green accents, terminal/code-inspired elements, bold typography, animations, interactive sections and responsive layouts.

## 3. Hero Section

> Create an animated hero section for "The Last Commit" with a terminal-inspired visual style, system status indicator, large typography, CTA buttons, subtle cursor interaction and developer-themed metadata.

## 4. Website Sections

> Suggest and structure sections for a hackathon website including an introduction/story, mission, statistics, challenge information, timeline, FAQ and final call-to-action while maintaining a consistent developer/terminal visual theme.

## 5. Registration Page

> Create a React and TypeScript registration form for a hackathon. Collect participant name, email, phone, year, college, department and team name. Submit the form to an Express backend API and display a successful registration message.

## 6. Backend API

> Create a Node.js, TypeScript and Express backend for a hackathon registration website. Provide an API endpoint to register participants and store their information in MongoDB using Mongoose.

## 7. Admin Authentication

> Create an admin login system for an Express backend using username and password authentication with JWT. Protect admin routes using authentication middleware.

## 8. Admin Dashboard

> Create a React and TypeScript admin dashboard for a hackathon registration system. Display registered participants, total participants, total teams, year distribution and college distribution. Include search, year filtering and CSV export functionality.

## 9. Database

> Design a MongoDB/Mongoose participant model containing name, email, phone, year, college, department, team name and registration timestamp.

## 10. Deployment

> Explain how to deploy a React/Vite frontend to Vercel and a Node.js/Express TypeScript backend to Render, while connecting the backend to MongoDB Atlas using environment variables.

## 11. Debugging

> Help identify and fix frontend alignment, styling, API connection and deployment issues without changing unrelated parts of the project.

## 12. Code Quality

> Review the project structure and suggest improvements while keeping the implementation simple, maintainable and suitable for a student hackathon project.

---

## AI Usage Note

AI assistance was used as a development aid for brainstorming, UI ideas, code suggestions, debugging, deployment guidance and documentation.

The final project was reviewed, integrated and tested manually by the developer.
